# Edencorp

Edencorp builds bespoke AI systems and custom software for businesses across industries. We study how each business works, then design and build around its needs. Projects can include AI agents, copilots, decision systems, autonomous pipelines, or other software engineering work. The scope follows the problem, not a fixed package.

**Start a project:** [Check fit on Edencorp's website](https://edencorp.org/#fit). Tell us what you need to build or improve. If the project fits, we discuss the work before setting a paid audit or build scope.

**Contact:** [edencorp-org@mail.tin.computer](mailto:edencorp-org@mail.tin.computer)

Edencorp is not a registered legal entity.
